# glance v11.0.3

## Highlights

- Enforced strict checksum policy by allowing only sha256 and sha512 across CLI, downloader, uploader, and verifier flows
- Added a security CI workflow that runs go mod verify, go build, go test, go vet, and govulncheck on push and pull request
- Added explicit FTP security guard: ftp sources are disabled by default and require allow-insecure-ftp opt-in
- Added regression tests for checksum algorithm restrictions and FTP opt-in parsing
- Updated Go toolchain pinning to a patched version to address standard library vulnerability findings

## Install

```bash
go install github.com/procyberian/glance/v11@v11.0.3
```

## Build From Source

```bash
git clone git@github.com:procyberian/glance.git
cd glance
git checkout v11.0.3
go build -o glance .
```
