# glance v11.0.0

## Highlights

- Go module line updated to `github.com/procyberian/glance/v11`
- Recursive FTP ISO discovery with checksum-aware selection
- Recursive HTTP/HTTPS directory discovery across parent and child paths on the same host
- Interactive ISO selection with single, multiple, or `all` choices
- Resume-aware downloads with `.download` files and `--no-resume`
- Interactive upload file selection when `--file` is not provided
- Configurable `--scan-timeout` for HTTP/FTP directory scans

## Install

```bash
go install github.com/procyberian/glance/v11@latest
```

## Build From Source

```bash
git clone git@github.com:procyberian/glance.git
cd glance
git checkout v11.0.0
go build -o glance .
```
