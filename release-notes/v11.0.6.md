# glance v11.0.6

## Highlights

- Dependency security update: `golang.org/x/crypto` bumped to `v0.53.0`, which contains upstream security and bug fixes.
- All other direct and indirect dependencies refreshed to their latest compatible versions.
- Full test coverage added for the previously untested packages: `internal/keygen`, `internal/license`, `internal/uploader`, and `pkg/glance`.

## Changes

### Dependency Updates

| Module | Old | New |
|---|---|---|
| `golang.org/x/crypto` | v0.50.0 | v0.53.0 |
| `golang.org/x/sys` | v0.43.0 | v0.46.0 |
| `github.com/jlaffaye/ftp` | v0.2.0 | v0.2.1 |
| `github.com/hashicorp/errwrap` | v1.0.0 | v1.1.0 |
| `go` directive | 1.25.0 | 1.26 |

Unused indirect dependencies removed by `go mod tidy`.

### New Test Files

- `internal/keygen/keygen_test.go` — covers all key generation algorithms (ed25519, RSA, ECDSA), default algorithm fallback, custom key names, unsupported algorithm rejection, and private key permission enforcement.
- `internal/license/license_test.go` — asserts the license constant is non-empty and contains the expected MIT header, copyright, and warranty disclaimer text.
- `internal/uploader/uploader_test.go` — validates config rejection for missing host, user, and local file; confirms default port logic.
- `pkg/glance/glance_test.go` — exercises the full public API: version and license constants, help text, flag parsing, `Execute` short-circuit paths, hash calculation and verification (sha256/sha512), and key pair generation.

## Install

```bash
go install github.com/procyberian/glance/v11@v11.0.6
```

## Build From Source

```bash
git clone git@github.com:procyberian/glance.git
cd glance
git checkout v11.0.6
go build -o glance .
```
