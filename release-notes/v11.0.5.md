# glance v11.0.5

## Highlights

- Added live upload progress reporting: percentage, instant speed, average speed, and ETA are now displayed during every SSH/SFTP transfer.
- Added upload resume support: if a partial remote file exists and `--no-resume` is not set, the uploader seeks the local file to the remote offset and appends instead of overwriting.
- Added `--version` flag and `version` subcommand: prints the current release string and exits.
- Added `--json` flag: writes a structured JSON result to stdout after all operations complete, enabling scripted and CI usage without screen-scraping. Fields: `downloaded_path`, `checksum`, `checksum_algorithm`, `uploaded`, `remote_host`, `remote_file`.
- Added `--connect-timeout` flag (default 30 s): sets a hard TCP dial timeout for HTTP/HTTPS downloads, preventing indefinite hangs on unresponsive servers.
- Exported `DownloadISOWithConnectTimeout` in `pkg/glance` for library consumers.
- Exported `Version` constant from both `internal/cli` and `pkg/glance`.

## Install

```bash
go install github.com/procyberian/glance/v11@v11.0.5
```

## Build From Source

```bash
git clone git@github.com:procyberian/glance.git
cd glance
git checkout v11.0.5
go build -o glance .
```
