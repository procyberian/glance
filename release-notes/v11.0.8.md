# glance v11.0.8

## Highlights

- `scripts/publish-release.sh` now prompts interactively for API tokens when they are not set as environment variables, so the script no longer exits immediately if you simply run it without pre-exported tokens.

## Changes

### Script Enhancement

- **Interactive token prompting**: when `GH_TOKEN` or `CODEBERG_TOKEN` are not set and the script is running in an interactive terminal (`-t 0`), the script prompts the user to type each token with `read -rsp` (input is hidden and not echoed). Non-interactive environments (CI pipelines, pipes) still require the tokens as environment variables and exit with a clear error if absent.

## Install

```bash
go install github.com/procyberian/glance/v11@v11.0.8
```

## Build From Source

```bash
git clone git@github.com:procyberian/glance.git
cd glance
git checkout v11.0.8
go build -o glance .
```
