# glance v11.0.11

## Highlights

- Security maintenance release: Go toolchain pinned to `go1.26.9` (standard-library security fixes) and dependency updates.
- SSH private-key generation now enforces `0600` permissions, including when replacing an existing key file.
- Binary archives now cover macOS, Windows, Linux, and BSD targets.

## Changes

### Security

- Pinned the Go toolchain to `go1.26.9`.
- Upgraded `golang.org/x/crypto` from `v0.57.0` to `v0.58.0` and `golang.org/x/sys` from `v0.48.0` to `v0.49.0`.
- `glance --keygen` now sets `0600` on the private key file even if a more permissive file already existed; a regression test covers this.
- Removed `scripts/publish-release.sh`; releases are published manually.

### Security Notes

- `govulncheck ./...` reports no vulnerabilities in reachable code.
- `GO-2026-5932` (unmaintained `golang.org/x/crypto/openpgp`) remains listed at module level only; glance does not import that package and no upstream fix exists.

## Install

```bash
go install github.com/procyberian/glance/v11@v11.0.11
```

## Build From Source

```bash
git clone git@github.com:procyberian/glance.git
cd glance
git checkout v11.0.11
go build -o glance .
```
