# glance v11.0.9

## Highlights

- Dependency maintenance release with updated SSH/SFTP and crypto modules.

## Changes

### Dependency Updates

- Upgraded `github.com/pkg/sftp` from `v1.13.10` to `v1.13.11`.
- Upgraded `golang.org/x/crypto` from `v0.53.0` to `v0.54.0`.
- Upgraded `golang.org/x/sys` from `v0.46.0` to `v0.47.0`.
- Refreshed module metadata and checksums with `go mod tidy`.

## Install

```bash
go install github.com/procyberian/glance/v11@v11.0.9
```

## Build From Source

```bash
git clone git@github.com:procyberian/glance.git
cd glance
git checkout v11.0.9
go build -o glance .
```
