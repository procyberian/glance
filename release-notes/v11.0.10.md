# glance v11.0.10

## Highlights

- Security and dependency maintenance release following a full review of the source code and configuration (no exploitable issues found).
- Resolves the SSH denial-of-service advisories that affected `golang.org/x/crypto` `v0.54.0`.

## Changes

### Dependency Updates

- Upgraded `golang.org/x/crypto` from `v0.54.0` to `v0.57.0`.
- Upgraded `github.com/jlaffaye/ftp` from `v0.2.1` to `v0.2.4`.
- Upgraded `golang.org/x/sys` from `v0.47.0` to `v0.48.0`.
- Upgraded `golang.org/x/term` from `v0.45.0` to `v0.46.0`.
- Upgraded test dependency `github.com/stretchr/testify` from `v1.11.1` to `v1.12.1`.
- Refreshed module metadata and checksums with `go mod tidy`; `go mod verify` passes.

### Security Notes

- `govulncheck ./...` reports no vulnerabilities in reachable code.
- `GO-2026-5932` (unmaintained `golang.org/x/crypto/openpgp`) remains listed at module level only; glance does not import that package and no upstream fix exists.

## Install

```bash
go install github.com/procyberian/glance/v11@v11.0.10
```

## Build From Source

```bash
git clone git@github.com:procyberian/glance.git
cd glance
git checkout v11.0.10
go build -o glance .
```
