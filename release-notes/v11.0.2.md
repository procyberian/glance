# glance v11.0.2

## Highlights

- Added a reusable public Go package at `pkg/glance` for library consumers
- Added automated release publishing support for GitHub and Codeberg
- Added `--github-only`, `--codeberg-only`, and `--dry-run` to the release publishing workflow
- Added `--dist-dir` and `--notes-file` so release inputs can be overridden from the command line
- Expanded README documentation for binary downloads, library usage, token requirements, and release publishing examples

## Install

```bash
go install github.com/procyberian/glance/v11@v11.0.2
```

`go install` does not download one of the release archive assets. It builds `glance` for the current machine's Go target, so Linux `amd64`, Linux `arm64`, macOS `amd64`, macOS `arm64`, and Windows `amd64` users each get a binary for their own environment when Go is installed locally.

## Build From Source

```bash
git clone git@github.com:procyberian/glance.git
cd glance
git checkout v11.0.2
go build -o glance .
```

## Release Assets

Use the release assets when you want a prebuilt binary without installing Go first.

- Linux x86_64: `glance-linux-amd64.tar.gz`
- Linux ARM64: `glance-linux-arm64.tar.gz`
- macOS Intel: `glance-darwin-amd64.tar.gz`
- macOS Apple Silicon: `glance-darwin-arm64.tar.gz`
- Windows x86_64: `glance-windows-amd64.zip`
